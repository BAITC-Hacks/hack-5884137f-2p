# FAQ-бот для репетиции

Простой терминальный чат-бот, отвечающий на 5 заранее известных вопросов
про репетицию хакатона: время, команда, трек, сдача, призы.

## Как запустить

Нужен только Python 3 (без внешних зависимостей).

```bash
python3 bot.py
```

Бот прочитает `faq.txt` (должен лежать рядом со скриптом) и откроет
диалог в терминале:

```
> во сколько начало?
Репетиция начинается в 10:00 в главном зале, регистрация с 9:30.
> exit
Пока!
```

Выход — командой `exit`, `quit`, `выход` или Ctrl+C.

## Что получилось

- **faq.txt** — 5 пар вопрос/ответ (время, команда, трек, сдача, призы),
  разделены пустой строкой: первая строка блока — вопрос, вторая — ответ.
- **bot.py** — читает `faq.txt`, токенизирует вопросы (убирает стоп-слова,
  приводит к нижнему регистру), для вопроса пользователя ищет FAQ-вопрос
  с максимальным пересечением ключевых слов (метрика похожа на
  коэффициент Жаккара: |пересечение| / |объединение|). Если лучшее
  совпадение ниже порога (`MIN_SCORE = 0.2`, минимум 1 общее слово) —
  бот отвечает «Не знаю.».
- RAG/эмбеддинги не использовались — по условию задачи достаточно
  совпадения по ключевым словам, задача рассчитана на 30–60 минут.

## Ограничения / что можно улучшить при наличии времени

- Точность зависит от формулировки — синонимы («когда» vs «во сколько»)
  не распознаются без совпадения хотя бы одного словоформы.
- Нет стемминга/лемматизации, поэтому падежные формы слова иногда не
  совпадают («трека» vs «трек»).
- Пороги (`MIN_OVERLAP`, `MIN_SCORE`) подобраны вручную под 5 вопросов —
  при расширении базы их стоит пересмотреть.
